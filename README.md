# ATP - Preparação e Análise Exploratória de Dados

## Contexto
A empresa Enron foi uma companhia de energia americana, localizada em Houston no Texas. Tendo sido uma das empresas líderes no mundo em distribuição de energia (electricidade, gás natural) e comunicações. Seu faturamento atingia 101 bilhões de dólares no ano de 2000, pouco antes do escândalo financeiro que ocasionou sua falência.


## Relatório
Relatório completo sobre a base de dados de emails trocados entre funcionários, entre esses funcionários estavam as pessoas de interesse. Nesse relatório é relatado com gráficos e análises descritivas sobre as relações entre despesas, pagamento adiado e outros com as pessoas de interesse.

Criado no Jupyter Lab, com o código escrito em Python com bibliotecas para análise de dados.


## Bibliotecas utilizadas

- Pandas;
- Numpy;
- Seaborn;
- Matplotlib;

## Base de dados

- Emails trocados entre 150 funcionáros da Enron;
